مدرسه ی من — بسته بازطراحی ظاهری

محتویات:
- index.html: صفحه ورود/انتخاب نقش
- student.html: پنل دانش‌آموز
- parent.html: پنل والدین
- teacher.html: پنل معلم
- manager.html: پنل مدیریت
- madrese-theme.css: پوسته مشترک و طراحی یکپارچه
- school-live.js: نسخه اصلاح‌شده موجود در فایل‌های پروژه، برای صفحات مدیر و والدین

نصب در GitHub Pages:
1) از مخزن فعلی خود یک نسخه پشتیبان بگیرید.
2) فایل‌های همین بسته را در همان پوشه‌ای قرار دهید که فایل‌های HTML فعلی در آن هستند.
3) فایل‌های هم‌نام را جایگزین کنید و madrese-theme.css را نیز اضافه کنید.
4) ساختار پوشه‌ها و تنظیمات Supabase مخزن را تغییر ندهید.
5) پس از انتشار، ورود و نقش‌ها، پیام‌رسان، ثبت نمره و حضور و غیاب را با حساب‌های واقعی خود بررسی کنید.

نکته:
- این بسته فقط ظاهر را با CSS مشترک هماهنگ می‌کند و شناسه‌های HTML را تغییر نمی‌دهد.
- طرح پایگاه داده، RLS و فایل SQL مهاجرت عمداً دست‌کاری یا اجرا نشده‌اند.
- فایل school-live.js از school-live-fixed.js موجود در فایل‌های قبلی پروژه تهیه شده است.
- آزمون انجام‌شده: بررسی نحوی JavaScript با node --check و مقایسه شناسه‌های HTML قبل و بعد.
- آزمون مرورگر واقعی، اتصال زنده Supabase، جریان‌های ورود و همه تعاملات به‌صورت end-to-end در این محیط قابل تأیید نبودند.
